# (VERY EARLY DEVELOPMENT) Anki Korean deck from beginner to academic level Korean #

Compiled from around 4 years of academic and selfstudy by miaumiaya (Chaei).

Entries: ~4.3k, unsorted, no definitions for most, no tags, no groupings, no extra information, no conjugational info, no word type, no difficulty yet.

This repo is currently in development, with only one variabel per entry for most entries. In the future, tags, definitions for multiple meanings (EN and KO), difficulty levels, and groups (eg. if you have a flash card for 교육 you will get 교육하다, 교육적, etc. along with the definition on the flipside.
